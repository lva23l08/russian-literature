# Техническое задание (ТЗ): Сайт «Русская литература»

## 1. Назначение
Сайт-галерея для знакомства с русскими писателями, их произведениями и цитатами. Платформа позволяет пользователям искать книги, читать сюжеты, сохранять избранное и делиться любимыми цитатами.

## 2. Технологии
- **Backend:** Python 3.11, Flask.
- **База данных:** SQLite.
- **Frontend:** HTML5, CSS3, JavaScript, шаблоны Jinja2.
- **Управление версиями:** Git и GitHub.

## 3. Функциональные возможности

### 3.1. Писатели и книги
- Галерея 20 русских писателей с горизонтальной прокруткой.
- Просмотр портрета, биографии и цитат писателя.
- Список произведений писателя с 3D-обложками книг.
- На странице книги: год написания и краткий сюжет.

### 3.2. Поиск и навигация
- Поле поиска по имени писателя на главной.
- Кнопки «XIX век» / «XX век» — фильтр по эпохе.
- Кнопка «Удиви меня» на главной — открывает страницу случайной книги.

### 3.3. Пользователи и личное
- Регистрация и вход по email/паролю.
- Личная полка: «Прочитано» и «Хочу прочитать».
- Избранное (сердечко) — добавление писателя в личный список.
- Счётчик просмотров на странице каждой книги.

### 3.4. Цитатник
- Раздел «Цитатник» — все цитаты пользователей.
- Кнопка «+ Добавить цитату» (текст, писатель, книга, имя).
- Каждая цитата — карточка с сердечком для лайка.
- «Цитата дня» на главной — случайная цитата.

## 4. Дизайн
- Белый фон, чёрно-белые фото (как на старых фотографиях).
- Рукописный шрифт для цитат.
- 3D-эффект при наведении на обложку книги.
- Плавные анимации перехода между страницами.
