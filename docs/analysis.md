# Анализ предметной области: Русская литература

## 1. Описание проекта
Проект «Русская литература» — это веб-сайт с русскими писателями и их портретами. На сайте представлены лучшие произведения русской литературы, цитаты, год написания и краткий сюжет книг. Дизайн стилизован под старые фотографии (белый фон, рукописные шрифты, плавные анимации).

## 2. Проблема и цель
**Проблема:** Информация о русских писателях и их книгах часто разбросана по разным сайтам. Нет единого красивого и удобного места, где можно было бы посмотреть портрет, почитать биографию, найти цитату и узнать сюжет книги.

**Цель:** Создать удобный сайт, где любой человек может найти книгу «по душе», открыть для себя что-то новое в русской литературе, а также поделиться любимыми цитатами.

## 3. Целевая аудитория
Сайт подходит для любой категории аудитории:
- **Школьники и студенты** — для подготовки к урокам литературы и сочинениям.
- **Учителя** — как наглядный интерактивный материал для уроков.
- **Любители литературы** — для поиска новых книг и сохранения прочитанного.
- **Иностранцы, изучающие русский язык** — для знакомства с культурой.

## 4. Сущности (что будет храниться в базе данных)
- **Писатель** (портрет, имя, годы жизни, эпоха, биография).
- **Книга** (обложка, название, год написания, сюжет, количество просмотров).
- **Цитата** (текст, к какому писателю и книге относится, лайки).
- **Пользователь** (имя, email, пароль).
- **Полка / Избранное** (какие книги пользователь прочитал или добавил в избранное).

## 5. Бизнес-процессы (как пользователь работает с сайтом)
1. **Просмотр галереи:** Пользователь заходит на главную и видит 20 портретов писателей. Их можно листать вправо-влево.
2. **Страница писателя:** При клике на портрет открывается биография, эпоха и список книг.
3. **Страница книги:** При клике на книгу открывается её сюжет, год написания, количество просмотров и 3D-обложка.
4. **Поиск и фильтр:** Пользователь может найти писателя через строку поиска или отфильтровать по эпохе (XIX или XX век).
5. **Цитатник:** Пользователь заходит в раздел «Цитатник», читает чужие цитаты, ставит лайки или добавляет свою (указывая автора и книгу).
6. **Регистрация:** После входа пользователь может сохранять книги в личную полку («Прочитано») и добавлять писателей в «Избранное».
