# Требования к проекту «Русская литература»

## Функциональные требования (FR) — 22 штуки

### Писатели и книги
| # | Требование |
|---|---|
| FR-01 | Просмотр галереи 20 русских писателей |
| FR-02 | Горизонтальная прокрутка галереи |
| FR-03 | Просмотр портрета и биографии писателя |
| FR-04 | Просмотр списка книг писателя |
| FR-05 | Просмотр обложки книги (3D-эффект) |
| FR-06 | Отображение года написания книги |
| FR-07 | Просмотр краткого сюжета книги |
| FR-08 | Отображение цитат на странице писателя |

### Поиск и навигация
| # | Требование |
|---|---|
| FR-09 | Поиск писателя по имени |
| FR-10 | Фильтр писателей по эпохе (XIX, XX век) |
| FR-11 | Кнопка «Удиви меня» — случайная книга |
| FR-12 | Счётчик просмотров книги |

### Регистрация и личное
| # | Требование |
|---|---|
| FR-13 | Регистрация нового пользователя |
| FR-14 | Вход в систему по email и паролю |
| FR-15 | Личная полка: «Прочитано» и «Хочу прочитать» |
| FR-16 | Избранное — добавление писателя в список |
| FR-17 | Оценка книги (1–5 звёзд) |

### Цитатник
| # | Требование |
|---|---|
| FR-18 | Просмотр всех цитат на странице «Цитатник» |
| FR-19 | Добавление цитаты: текст + писатель + книга |
| FR-20 | Лайк цитаты (сердечко) |
| FR-21 | «Цитата дня» на главной странице |
| FR-22 | Поиск цитаты по тексту или писателю |

## Нефункциональные требования (NFR) — 8 штук

| # | Требование |
|---|---|
| NFR-01 | Белый минималистичный дизайн, как на старых фото |
| NFR-02 | Плавные анимации при переключении страниц |
| NFR-03 | 3D-эффект при наведении на обложку книги |
| NFR-04 | Адаптивность — работает на телефоне |
| NFR-05 | Быстрая загрузка — до 2 секунд |
| NFR-06 | Безопасность — пароли хешируются, JWT-токены |
| NFR-07 | Понятный интерфейс — без объяснений |
| NFR-08 | Работает в Chrome и Firefox |
