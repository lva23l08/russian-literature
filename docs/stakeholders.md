# Стейкхолдеры проекта «Русская литература»

## 1. Кто будет пользоваться сайтом?

| Кто это | Зачем ему сайт |
|---|---|
| **Школьники** | Подготовка к урокам литературы, поиск сюжета для сочинения |
| **Студенты-филологи** | Изучение биографий писателей и цитат |
| **Учителя** | Наглядный материал для уроков, возможность поделиться цитатой |
| **Любители чтения** | Поиск новых книг «по душе», ведение списка прочитанного |

## 2. User Stories (Истории пользователей)

*Шаблон: «Я как [кто], хочу [что], чтобы [зачем]»*

- **US-01:** Я как **школьник** хочу быстро найти сюжет книги, чтобы написать сочинение.
- **US-02:** Я как **учитель** хочу показать портрет писателя, чтобы рассказать о нём классу.
- **US-03:** Я как **любитель литературы** хочу добавить книгу в «Избранное», чтобы прочитать её позже.
- **US-04:** Я как **пользователь** хочу добавить красивую цитату, чтобы поделиться ею с другими.
- **US-05:** Я как **студент** хочу отфильтровать писателей по эпохе, чтобы найти нужный период.
- **US-06:** Я как **пользователь** хочу нажать кнопку «Удиви меня», чтобы открыть для себя случайную книгу.
