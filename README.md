# 📚 Русская литература — интерактивная платформа

[Главный экран](main.png)

**Русская литература** — это атмосферный веб-сайт, который знакомит пользователей с жизнью и творчеством великих русских писателей. Проект объединяет удобную навигацию по галерее классиков, базу данных их произведений, случайные цитаты и систему авторизации. Дизайн сайта стилизован под старый Петербург с использованием анимированного фона и эффекта матового стекла.

---

## ✨ Основные возможности

- **Галерея писателей:** 11 великих классиков (от Пушкина до Есенина) с портретами и годами жизни. Карточки имеют 3D-эффект при наведении и горизонтальную прокрутку.
- **Страницы писателей:** Индивидуальная страница для каждого автора с краткой биографией и списком его главных произведений.
- **Карточки книг:** Произведения оформлены в виде темных обложек. У каждой книги указан год написания и краткий сюжет.
- **Цитата дня:** На главной странице при каждом обновлении появляется случайная цитата из базы данных.
- **Атмосферный дизайн:** Цветной фон с видом на Исаакиевский собор (с эффектом медленного приближения), полупрозрачные блоки с размытием (Glassmorphism).
- **Регистрация и вход:** Полноценная система аккаунтов с безопасным хешированием паролей.

---

## 🛠️ Используемые технологии и библиотеки

Проект написан на языке **Python** с использованием следующих инструментов:

| Технология / Библиотека | Для чего используется |
| :--- | :--- |
| **Python 3.10+** | Основной язык программирования. |
| **Flask** | Легковесный веб-фреймворк для маршрутизации и рендеринга HTML-страниц. |
| **Flask-SQLAlchemy** | ORM (Object-Relational Mapping) для удобной работы с базой данных через классы Python. |
| **SQLite** | Встроенная база данных (файл `library.db`), не требующая отдельного сервера. |
| **Werkzeug** | Библиотека для безопасного хеширования паролей пользователей (PBKDF2). |
| **python-dotenv** | Загрузка секретных настроек (например, `SECRET_KEY`) из файла `.env`. |
| **HTML5 / CSS3** | Верстка страниц и создание анимаций (без использования тяжелых JS-фреймворков). |

## ⚙️ Как это работает?

1. Пользователь заходит на главную страницу и видит фоновое изображение Петербурга, случайную цитату и карусель писателей.
2. При клике на писателя срабатывает маршрут `@app.route('/writer/<id>')`. Сервер ищет писателя в базе по его ID и загружает связанные с ним книги.
3. Для добавления книг в базу используется скрипт `seed_books.py`, который связывает таблицу `Book` с таблицей `Writer` через внешний ключ.
4. При регистрации пароль пользователя не сохраняется в открытом виде: библиотека Werkzeug превращает его в хеш, и только он попадает в базу данных.
